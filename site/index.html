01What it does

Invitations at a glance

Guests are grouped by category and place. See how many families are done, how many people that is and who is still pending — tick a family off with one tap.

A gift and expense ledger

Record shagun and gifts received next to what the event costs. Totals, the balance and anything still unpaid update as you go.

Bring your list along

Import an existing guest list or ledger from CSV, and export it again whenever you need a copy to share or print.

Yours, not ours

No account and no server. Everything lives in a database on your device; the web version keeps it in your browser.

02Offline and private

Event Manager has no backend, so there is nowhere for your guest list to go. Names and amounts stay in the app's local database and only leave when you export them.

The web version opens with fictional sample data, so you can try everything straight away.

03Get Event Manager

Use it right here in your browser, or install it. Every GitHub release carries builds for Android, Windows, macOS and Linux.
